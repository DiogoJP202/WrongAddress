# place/

- `WrongAddress.rbxl` — place do P0. Criar um Baseplate no Roblox Studio e usar **File → Save to File As** com este nome, nesta pasta.
- `backups/` — cópias datadas do `.rbxl`, feitas antes de cada sessão de implementação. Fora do git.

O Studio é a fonte única dos scripts do jogo (ver `docs/15-PLANO-P0.md`, decisão Q3). Não manter cópias editáveis dos scripts fora do Studio.
